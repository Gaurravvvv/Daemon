## 2. Frameworks & Major Libraries

### A. Orchestrator Backend (`/orchestrator`)
- **FastAPI (`fastapi`)**: Modern, high-performance async REST framework powering the master API routes.
- **Uvicorn (`uvicorn`)**: Lightning-fast ASGI server running the FastAPI application.
- **Motor (`motor`)**: Asynchronous Python driver for MongoDB.
- **Pika (`pika`)**: Enterprise AMQP client managing RabbitMQ channel pools and task publishing.
- **Boto3 (`boto3`)**: AWS S3 SDK configured for self-hosted MinIO object storage.
- **Pydantic (`pydantic`)**: Data validation and request/response schema modeling.
- **python-multipart**: Multipart form-data handling for direct dataset ZIP uploads.

### B. Worker Daemon (`/worker`)
- **Pika (`pika`)**: Persistent AMQP blocking connection listening on worker-specific queues (`prefetch_count=1`).
- **CuPy (`cupy-cuda12x`)**: NumPy-compatible GPU matrix and tensor computation library compiled against CUDA 12.x.
- **NumPy (`numpy`)**: Vectorized CPU numerical computation and BLAS operations.
- **Pillow (`Pillow==11.1.0`)**: High-performance image loading, spatial manipulation, and formatting.
- **Boto3 (`boto3`)**: S3 client for presigned chunk retrieval and result uploads.
- **Requests (`requests`)**: HTTP client for worker registration, progress pings, and event dispatch.

### C. Dashboard Frontend (`/dashboard`)
- **Next.js 15+ (App Router)**: Hybrid server/client rendering framework.
- **React 19**: Modern component lifecycle, hooks (`useState`, `useEffect`, `useRef`), and streaming.
- **Tailwind CSS**: Utility-first styling engine implementing the dark terminal aesthetic.
- **Lucide React / Material Symbols**: System status icons, active dots, and terminal glyphs.
- **next-themes**: Dark mode theme provider.

## 4. Environment Variables Reference

| Variable | Target Subsystem | Default Value | Description |
| :--- | :--- | :--- | :--- |
| `ORCHESTRATOR_URL` | Worker, Dashboard | `http://localhost:8000` | Network endpoint of the FastAPI orchestrator master. |
| `RABBITMQ_URL` | Worker, Orchestrator | `amqp://guest:guest@localhost:5672/` | AMQP broker connection URI. |
| `MINIO_URL` | Worker, Orchestrator | `http://localhost:9090` | Self-hosted S3 API endpoint. |
| `MINIO_ACCESS_KEY` | Worker, Orchestrator | `Gaurav` | MinIO root access credentials. |
| `MINIO_SECRET_KEY` | Worker, Orchestrator | `password123` | MinIO root secret credentials. |
| `MONGO_URI` | Orchestrator | `mongodb://localhost:27017` | Persistent metadata store connection string. |
| `REDIS_URL` | Orchestrator | `redis://localhost:6379` | In-memory heartbeat and cache registry URI. |
| `POOL_ID` | Worker, Orchestrator | `public_pool` | Workload routing pool or private cluster identifier. |
| `FORCE_CPU` | Worker | `0` | When set to `1`, forces worker into CPU mode even if CUDA GPU is present. |
| `GPU_DEVICE_ID` | Worker | `0` | Target CUDA physical device index on multi-GPU machines. |
