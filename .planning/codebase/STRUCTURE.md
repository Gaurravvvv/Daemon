## 2. Key Component Responsibilities

| File Path | Primary Function | Key Dependencies |
| :--- | :--- | :--- |
| `orchestrator/main.py` | Initializes FastAPI app, opens DB connections, starts background aggregator. | `fastapi`, `motor`, `asyncio` |
| `orchestrator/api/routes.py` | Handles all HTTP endpoints, uploads files to MinIO, pushes tasks to RabbitMQ. | `fastapi`, `boto3`, `pika` |
| `orchestrator/core/splitter.py` | Partitions monolithic jobs into micro-task manifests with compute mode tags. | Standard library (`uuid`) |
| `orchestrator/core/aggregator.py` | Monitors completion states and stitches partial chunks into master outputs. | `motor`, `boto3`, `asyncio` |
| `worker/main.py` | Detects GPU hardware via CuPy active smoke-test, registers node, boots consumer. | `cupy`, `requests`, `sys` |
| `worker/consumer.py` | AMQP task consumer, compute eligibility gating, strategy execution, progress ack. | `pika`, `requests`, `time` |
| `worker/strategies/image_processing.py` | 2D Sobel edge detection & histogram contrast enhancement on GPU or CPU. | `cupy`, `numpy`, `PIL` |
| `worker/strategies/matrix_strategy.py` | High-performance distributed block matrix multiplication via BLAS/CuPy. | `numpy`, `cupy`, `json` |
